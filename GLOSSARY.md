# Skills

Ahmed Gharib's shared agent skills. Each skill is written once here and reaches a repo as a derived copy; a repo expresses its own differences through per-repo docs, leaving its copy as installed.

## Language

One glossary in several files, one per area, so a session reads only the area it works in. A term lives in exactly one file, and each entry is the bold term, its definition, then an `_Avoid_` line.

- [Ship run](docs/glossary/ship-run.md): Ship, its lanes, runs, gates and hand-offs.
- [Ship run: host and test mechanics](docs/glossary/ship-run-mechanics.md): the host, host fakes, fixture repos, live runs, the run file and the self-review loop.
- [Profiles](docs/glossary/profiles.md): the ship and harness profiles, axes and setup.
- [Harness](docs/glossary/harness.md): the check entry point, rungs, budgets, stacks and members.
- [Distribution and Refresh](docs/glossary/distribution-and-refresh.md): derived copies, consumer repos, pinned refs and the release run.
- [Review](docs/glossary/review.md): reviewers, triggers and review rounds.
- [Grilling](docs/glossary/grilling.md): the grilling round.
- [Supervision](docs/glossary/supervision.md): driving sessions in Herdr.
- [Explainer video](docs/glossary/explainer-video.md): the explainer-video skill's vocabulary.
- [Creative video](docs/glossary/creative-video.md): the `creative-video` skill's vocabulary, the freely authored sibling of `explainer-video`.
- [Retro run](docs/glossary/retro.md): the retro run over a week's merged PRs.

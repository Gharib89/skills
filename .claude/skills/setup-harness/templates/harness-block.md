### Harness

`scripts/check.sh` is this repo's check entry point: `edit <file>...` lints and formats, `turn` {turn}, and `full` answers for the whole repo: {full}. It prints one JSON line and exits 0 pass, 1 fail, 2 unavailable, 3 over budget. Hooks in `.claude/settings.json` run `edit` after every Edit or Write and `turn` at every stop, and the pre-commit runner is the commit rung. Harness profile: `docs/agents/harness.md`. Re-run `/setup-harness` after adding a stack, a member or a tool.

With a language server wired, use `LSP` `goToDefinition` rather than grep to find where a symbol lives, and before changing a function's signature or renaming a symbol, call `findReferences` on it and cross-check the list with a grep for the name. If a session's first `findReferences` returns only the declaration, the server had not finished indexing, so retry once. Trust neither source alone: a file changed through Bash stays invisible to the server for the rest of the session, and grep misses aliased imports and attribute access. The server roots at the folder the session was in at its first `LSP` call and never moves, so in a worktree reached by path (a Bash `cd`, or ship's `isolate`), `LSP` answers and diagnostics read the main checkout's code: use grep there.

Super Agent Message Look

Three looks for the six texts the super agent's scripts print: the needs-you message, the no-change line, the away line, the return digest, the need thread's title and its reminder. Pick one look, or name the parts you want from each.

  • Already fixed, the same in every look: the action sits in the first 80 characters, one clause of why, numbered options with the recommended one first, and the digest opens with the open needs.
  • Each message is drawn at phone width. The link colour and list style are a stand-in for the T3 thread view.

# Retired terms

Words and file names explainer-video stopped using, one row each: the
explainer-video version that retired it, the word, and the word that replaces
it (`None.` where nothing does). `update-skills` plans every row inside the
version range a refresh crosses, replaces the word in the consumer repo's own
documents and renames a file whose name is the word. A PR that retires a word
adds its row here in the same diff. A cell holds no `|`.
